# Street Print — model-growth concept

`model-growth-v1.png` is an AI-generated design reference, **not a screenshot or
an implemented feature**. It records the selected direction before prototyping.

- Keep a continuous map ground; no island, sea or floating terrain.
- Grow decorative low-rise white model buildings near repeatedly walked roads.
- Use stable placements with capped density, height and occupied area.
- Keep roads and intersections clear of decorative buildings.
- Use reusable simple meshes and inexpensive materials/shadows in a dedicated
  3D model view; RealityKit is a candidate, not a verified implementation yet.
- Do not imply that the decorative buildings reproduce actual buildings.
- Preserve existing screen-space controls and stats placement.
- Verify map/model alignment, attribution, hit testing, memory and device frame
  rate before treating the visual fidelity in this mockup as an achievable result.

Image generation: built-in image generation, followed by a UI-layout correction.
Prompt summary: an implementable portrait Street Print UI, pale map ground,
blue visited routes, repeated low-rise white primitive buildings and simple trees;
frequent corridors are fuller, occasional branches sparse, unvisited areas flat.
No islands, towers, dramatic lighting, or changes to the existing UI arrangement.
