# Street Print — Your Personal Route Map

移動した道路を自動で記録し、自分だけの生活圏を地図として育てるiOSアプリのMVPです。SwiftUI、MapKit、Core Locationで構成し、移動履歴は端末内へ保存します。

## 実装済み

- 初回セットアップ（位置情報・常時許可・自動記録の説明と権限要求）
- 3段階の記録モード（常時記録／バックグラウンドまで／計測オフ）
- 強制終了後の大幅な位置変化による復帰と、空白区間の道路経路推定
- 徒歩・自転車・車・鉄道など、速度や移動手段を問わない記録
- 速度に応じたAppleマップの徒歩／自動車経路による道路補正（失敗時はGPS軌跡へフォールバック）
- 通過頻度に応じた経路の濃さ・太さの変化
- 地図ビュー／経路だけビューのワンタップ切り替え
- 「今月／今年／すべて」と開始日〜終了日の二点スライダー
- 新しい道、移動距離、アクティブ日数
- Editorial Glass、Midnight Pulse、Modern Paper Atlas、Neural、Acid Trailの5テンプレート
- 経路だけを使った縦長SNS共有画像
- ローカルJSON保存と全履歴削除
- Debugビルド用のプレビューサンプル追加

## 起動方法

1. `Michi.xcodeproj` をXcodeで開きます。
2. Michiターゲットの Signing & Capabilities で自分のTeamを選びます。
3. GPSとモーションを確認できる実機を選び、Runします。
4. 初回案内で位置情報を「常に許可」にします。

プロジェクト設定を再生成する場合は、リポジトリ直下で `xcodegen generate` を実行します。

## 実機確認時の注意

- 「常時記録」は連続測位に加えて大幅な位置変化を監視し、終了後の復帰と推定経路補完を試みます。
- 「バックグラウンドまで」はホーム画面・画面ロック中も連続測位しますが、プロセス終了後の復帰と推定補完は行いません。
- 「計測オフ」は移動経路の計測と保存を停止します。
- Appスイッチャーから強制終了すると高精度な連続測位はいったん止まります。「常に許可」と大幅な位置変化の監視が有効なら、iOSから位置イベントを受けた際に復帰します。
- 復帰時は最後の実測地点と新しい地点の間（3分〜24時間、100m〜200km）をAppleマップの道路経路で補完し、薄い破線の「推定経路」として保存します。
- 安定した再開のため位置情報は「常に許可」を推奨します。「使用中のみ」でも青い位置情報インジケータを表示するバックグラウンドセッション中は記録を継続します。
- iOS 17以降ではバックグラウンド活動セッションも保持し、ホーム画面・画面ロック中の連続更新を維持します。
- 記録中の経路は15秒間隔で下書き保存し、OSによる終了後も次回起動時に復元します。
- 移動手段による除外は行わないため、車両や鉄道の移動も記録されます。
- 道路補正は速度に応じてAppleマップへ徒歩または自動車経路を問い合わせます。鉄道区間やオフライン時は生のGPS軌跡を保存し、記録自体は失いません。
- 「新しい道」はMVPでは道路区画の空間・方向バケットを端末内で比較した近似値です。
